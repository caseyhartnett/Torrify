# Getting Started

If you are deciding between the web app and the desktop app, start with the web app unless you already know you need local tooling.

<div class="runtime-note">
  <strong>Rule of thumb:</strong> the web app is the easiest on-ramp, and the desktop app is the richer long-term workspace.
</div>

## Which One Should You Pick?

| If you want to... | Best choice | Why |
| --- | --- | --- |
| Try Torrify quickly | Web app | Fastest path to editor + chat + preview |
| Learn the workflow with minimal setup | Web app | No local CAD install needed |
| Use build123d or Python CAD | Desktop app | Desktop includes the Python backend |
| Use Ollama or your own API keys | Desktop app | Desktop supports local and BYOK providers |
| Work with native file dialogs and recents | Desktop app | Desktop integrates directly with the OS |
