# Torrify Documentation

Torrify ships in two runtime shapes. The web app is the easiest place to begin, while the desktop app gives you the fuller feature set once you want deeper local workflows.

<div class="runtime-grid">
  <a class="runtime-card runtime-card--web" href="./getting-started/START_HERE.md">
    <span class="runtime-badge runtime-badge--web">Recommended First</span>
    <h3>Start on the Web App</h3>
    <p>Open Torrify in your browser and get to code quickly without a local OpenSCAD install.</p>
    <ul class="runtime-checklist">
      <li>Best for first-time users</li>
      <li>Managed AI access is built in</li>
      <li>Ideal for learning and quick experiments</li>
    </ul>
  </a>
  <a class="runtime-card runtime-card--desktop" href="./getting-started/installation.md">
    <span class="runtime-badge runtime-badge--desktop">More Features</span>
    <h3>Use the Desktop App</h3>
    <p>Install Torrify locally when you want the complete CAD workflow and local tooling.</p>
    <ul class="runtime-checklist">
      <li>OpenSCAD and build123d</li>
      <li>Native file dialogs and recent projects</li>
      <li>Ollama, BYOK, and offline-capable local work</li>
    </ul>
  </a>
</div>
